모바일 로컬 테스트 3안


🥇 안1: Chrome DevTools 기기 에뮬레이션 (즉시 사용 가능)
F12 → 기기 아이콘(📱) 클릭 → iPhone 15 Pro 선택


장점: 설치 없음, 배포 불필요, 즉시 정확한 뷰포트/DPR 시뮬
단점: 실제 iOS Safari 렌더링과 5~10% 차이 있음
지금 당장 쓸 수 있는 가장 빠른 방법. 첫번째 스크린샷 같은 결과 로컬에서 확인 가능.

🥈 안2: 로컬 IP로 실제 폰 접속 (같은 WiFi)
package.json 수정:


"dev": "next dev -p 5555 -H 0.0.0.0"
PC IP 확인 후 (예: 192.168.0.10) 폰에서 http://192.168.0.10:5555 접속


장점: 진짜 iOS Safari/Chrome으로 테스트, 배포 불필요
단점: 같은 WiFi 필요
🥉 안3: ngrok HTTPS 터널 (어디서든 실제 폰)

npx ngrok http 5555
# → https://xxxx.ngrok.io 생성 → 폰에서 접속

장점: 어디서든 실제 모바일, HTTPS (카메라/파일 API 동작)
단점: 무료 계정은 세션당 2시간 제한, 속도 약간 느림
비키트 추천: 안1 + 안2 병행
상황	방법
빠른 레이아웃 확인	안1 (DevTools)
카메라/파일 업로드 테스트	안2 (로컬 IP)
외부에서 QA	안3 (ngrok)
